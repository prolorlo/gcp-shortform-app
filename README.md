# 숏폼펫 (ShortFormPet)

숏폼 때문에 공부에 집중하기 어려운 20대 대학생·수험생을 위한 안드로이드 앱입니다.  
**인스타그램 릴스 · 유튜브 쇼츠** 시청 시간만 정밀하게 재고, 덜 볼수록 살아 움직이는 반려 캐릭터 **모찌**가 자라며, 줄인 시간을 학업 집중으로 연결합니다.

> **코더 에이전트(Coder LLM) 필독**: 코드를 수정하기 전에 반드시 루트의 **`DESIGN.md`**(UI/UX·디자인 토큰·화면 분리 규칙)와 이 **`README.md`**(측정 뷰 ID·도메인 수식·저장소·파일 구조)를 먼저 읽고 그대로 구현하세요. 외부 라이브러리(AndroidX·Compose 등)는 일절 추가하지 않으며 순수 Android 기본 프레임워크만 사용합니다.

## 도메인 규칙 및 정밀 측정 상수 명세 (구현 기준값)

코더 에이전트가 별도 문서 없이도 오차 없이 구현할 수 있도록 확정된 수치와 상수를 정리합니다.

### 1. 측정 대상 패키지 및 뷰 ID (`ShortFormDetector.kt`)
- **인스타그램 릴스 (`com.instagram.android`)**: 인정 뷰 ID = `clips_viewer_view_pager`, `reel_viewer_root` (하단 탭 아이콘 등 제외)
- **유튜브 쇼츠 (`com.google.android.youtube`)**: 인정 뷰 ID = `reel_player_page_container`, `reel_recycler`, `reel_watch_player` (**기존 `reel_progress_bar` 및 `TikTok`은 반드시 제거**)
- **4대 적립 조건**: ① 수집 동의 완료(`consentAccepted == true`) ② 화면 켜짐(`PowerManager.isInteractive`, 화면 OFF 시 최대 5초 유예 후 중단) ③ 최상단 활성 패키지 일치(`accessibility_service_config.xml`의 `packageNames` 제한을 제거하여 타 앱·홈 전환 즉시 0초 중단) ④ 인정 뷰 ID 노드가 `isVisibleToUser == true`이고 세로 높이가 **기기 물리 화면 높이(`WindowMetrics` / `Display.getRealMetrics`)의 60% 이상**.
- **휴식 쿠폰 ON 중 시청**: 오늘 총 시청 시간에는 합산하되, **순수 시청 시간(`t = 총 시청 - 쿠폰 시청`)**에서 제외하여 목표 초과·`H` 감소·정산 감점·알림·진입 안내에서 모두 면제합니다(쿠폰 만료 시각을 걸친 틱은 만료 전 잔여 ms만 면제 처리).

### 2. 행복도(`H`) 및 새벽 05:00 경험치(`Exp`) 수식 (`PetEngine.kt`)
- **행복/허기 `H` (`0 ~ 100`, 5단계 표정)**:
  - 표정 구간: `100~70`(활짝 웃음) / `69~40`(미소) / `39~20`(무표정·허기) / `19~10`(시무룩) / `9~0`(아픔·X눈).
  - **`알(EGG)` 단계는 `H` 변화 없음**, `Exp >= 10`으로 **`아기(BABY)` 부화 시 `H = 100` 시작**.
  - **감소(`H-`)**: 실제 시간 **20분(`1,200,000ms`)마다 `H - 1`** 자동 감소(하루 총 `-72`) + 당일 순수 시청 `t`가 목표 `G`(`30 <= G <= 60`분)를 넘기면 **초과 5분마다 `H - 1`** 추가 감소.
  - **회복(`H+`)**: ① 포켓몬고식 스와이프 밥 던지기 명중 시 **`H + 20`**(하루 1회) ② 시간대별 쓰다듬기 **`H + 5`**(`05:00~14:59` 최대 3회 + `15:00~04:59` 최대 3회 = 일 최대 `+30`; 한도 소진 후에도 쓰다듬기 모션·말풍선은 항상 작동하되 `H+` 없음) ③ 할 일 완료 간식 주기 회당 **`H + 15`**(하루 최대 3회 = `+45`, 일일 능동 회복 합계 최대 `+95`) ④ 새벽 05:00 정산 시 목표 달성 연속일수 보너스 **`H + (연속일수 × 5)`**.
- **새벽 05:00 정산 및 진화**:
  - 미측정일(접근성 서비스 비활성으로 측정 누락된 날)은 정산 제외 및 연속일수 보류.
  - 반비례 경험치 공식: **`gainExp = round(100.0 * G / (t + G))`** (`t = 0`이면 `+100`, `t = G`이면 `+50`).
  - **5단계 누적 `Exp` 기준**: `알(0)` → `아기(10)` → `어린이(110)` → `청소년(220)` → `어른(350)`.
  - **성장 모션 당일 보존**: 정산으로 진화했을 때 `pendingEvolutionDay = today`를 기록하여 **그날 앱을 열었을 때만 성장 모션을 1회 재생**하고, 다음 날까지 앱을 켜지 않았다면 모션 없이 성장 외형만 반영.

### 3. 집중 세션 · 휴식 쿠폰 · 알림 세부 기준
- **집중 세션 보상**: `5분 착수`(시작 마중물 피드백), `25분` 완주 → **휴식 쿠폰 `+5분`**, `50분` 완주 → **휴식 쿠폰 `+10분`** (하루 최대 `20분` 적립, 새벽 05:00 소멸). 세션 중 접근성 서비스를 끄거나 포기하면 실패 처리.
- **알림 충돌 및 쿨타임**: 누적 알림(목표 전 30분 / 초과 후 15분, 같은 날 이미 보낸 기준선 이하 재발송 금지)과 연속 알림(`1~45분` 주기, 5분 이상 이탈 시 리셋)이 동시에 겹치면 **누적 알림 1건만 발송**. 자발적 절제 칭찬(목표 이내에서 연속 알림 주기의 절반 이하·최소 1분 이상 시청 후 스스로 종료 시 빼꼼 모찌 1.5~2초 칭찬)은 **하루 최대 2회, 쿨타임 3시간**.

## 화면 구성 (4개 탭 완전 분리 구조)

1. **`모찌` 탭 (풀스크린 캐릭터 전용 창)**:
   - 카드 박스 없이 화면 전체를 **아늑한 실내 방(고양이 방석 위) 또는 들판 배경**으로 사용하며, 모찌가 한자리에 멈춰 있지 않고 자유롭게 돌아다니고 방석에서 쉽니다.
   - **행복도(`H`) 막대와 누적 경험치(`Exp`) 막대는 모두 화면 위쪽(Top HUD)에 배치**하며, 하단에는 `[밥 던지기]`와 `[간식 주기]` 액션 도크를 둡니다.
2. **`오늘·할 일` 탭 (시청 현황 및 학업 실행 창)**:
   - 오늘 본 숏폼 시간(순수 시청 vs 휴식 쿠폰 시청, 실시간 감지 상태 점, 쇼츠·릴스 앱별 막대)과 오늘의 할 일(최대 3개), 집중 세션 타이머(`5·25·50분`), 휴식 쿠폰·보호권을 한 흐름으로 관리합니다.
3. **`기록` 탭**: 최근 7일 시청 막대 그래프(`WeekChartView`), 한 줄 요약, 연속일수 주간 달성표, 최근 새벽 5시 정산 기록.
4. **`설정` 탭**: 하루 목표(`30~60분`), 연속 알림 주기(`1~45분`), 약속 시간표(최대 3개), 각종 오버레이·동적 아이콘 토글, 권한 상태, **사용 설명서 다시 보기**, 캐릭터 이름 변경, (디버그) 개발자 테스트.

## 빌드 및 실행

1. Android Studio에서 프로젝트를 엽니다 (`File → Open → ShortFormPet`).
2. Gradle 동기화 후 에뮬레이터 또는 실기기(Android 8.0 / API 26 이상)에서 실행합니다.
   - 명령줄(Windows): `gradlew.bat assembleDebug` → `app\build\outputs\apk\debug\app-debug.apk`
   - 명령줄(macOS/Linux): `./gradlew assembleDebug`
3. 런타임 외부 의존성 `0개` (`app/build.gradle.kts`의 `dependencies`에 AndroidX·Compose·외부 SDK를 추가하지 마세요).

## 처음 실행 흐름

1. **수집·개인정보 안내 시트**: 전송 항목과 비수집 항목을 확인하고 `"동의하고 시작"` 선택(미동의 시 측정·동기화 완전 중지).
2. **초기 사용 매뉴얼 모달 (`OnboardingManualSheet`)**: 정밀 측정 원리, 자율 배회 모찌 돌보기(`H`·밥 던지기), 집중 세션 차등 차단과 휴식 쿠폰, 2×2 위젯·빼꼼 모찌 사용법을 4장 슬라이드로 안내.
3. **권한 설정**:
   - **접근성 서비스 켜기**: `설정 → 접근성 → 설치된 앱 → 숏폼펫 시청 시간 측정` 허용 (Android 13+ APK 직접 설치 시 앱 정보 우측 상단 `⋮ → 제한된 설정 허용` 선행).
   - **알림 허용** (구간 알림 및 집중 세션 중 상단 고정 알림 표시용) 및 **배터리 최적화 제외**(권장).

## Firebase 일일 동기화 설정

`Sync.kt`의 `SyncConfig.FIREBASE_DB_URL`이 비어 있으면 기기 내부에만 저장(최대 60일 보존, 미전송 일자는 삭제 제외)합니다.

1. Firebase 콘솔에서 **Realtime Database**를 생성하고 주소를 `FIREBASE_DB_URL`에 입력합니다.
2. 데이터베이스 보안 규칙(쓰기 전용, 외부 읽기 차단):

```json
{
  "rules": {
    ".read": false,
    "daily": {
      "$anonId": {
        "$date": {
          ".write": true,
          ".validate": "newData.hasChildren(['anonId', 'date', 'watchSec'])"
        }
      }
    }
  }
}
```

새벽 5시 정산 직후 표준 `HttpsURLConnection`으로 `PUT <주소>/daily/<익명 ID>/<날짜>.json` 1건을 전송하며, 오프라인일 때는 대기 큐에 보관했다가 연결 시 재전송합니다. **화면 텍스트, 영상 제목, 계정, 캐릭터 이름, 할 일 원문은 절대 전송하지 않습니다.**
